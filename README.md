# ⏱️ Hourlog – Frontend

The **Hourlog Frontend** is the web interface of Hourlog, an application for tracking worked hours by project and by task, with automatic total-hours calculation and PDF report export.

Built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS 4** and **shadcn/ui**, using **TanStack Query** for API consumption and automatic deployment on **Vercel**.

## ✨ Features

- **JWT authentication** — login and sign-up, with the token persisted in `localStorage` and attached to every request by an Axios interceptor.
- **Protected routes** — `RequireAuth` validates token expiration before rendering the private area; `PublicRoutes` keeps authenticated users away from the login screen.
- **Project management** — create, edit, view and delete projects, with status (In progress, Paused, Completed, Finalized) and per-status colors.
- **Task management** — description, date, start time and end time per task, recalculating the project's total hours on every change.
- **Data table** — sorting, filtering and row actions built with TanStack Table.
- **PDF reports** — downloads the project report generated by the API and delivers it as a `Blob` in the browser.
- **Dark theme and responsive layout** — a custom CSS layer (`variables`, `dark`, `responsive`) on top of Tailwind.
- **Interface feedback** — toasts with Sonner and confirmation dialogs for destructive actions.

## ⚙️ Installation & Local Setup

### Requirements

- **Node.js 20+**
- The Hourlog API running locally, or the production API URL

### 1. Clone the repository

```bash
git clone https://github.com/evelynlacerda/hourlog.git
cd hourlog
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file at the project root:

```env
VITE_API_URL=http://localhost:3000
```

For production, point it to the deployed API:

```env
VITE_API_URL=https://hourlog-backend.vercel.app
```

### 4. Run in development mode

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

> The API allows CORS for `http://localhost:5173`, `http://localhost:3000` and `https://hourlog.vercel.app`. If you use a different port, add it to the backend's allowed origins.

## 🔐 Authentication

The token is stored in `localStorage` after login and sent automatically on every request:

```ts
api.interceptors.request.use((config) => {
	const token = localStorage.getItem("token");
	if (token) {
		config.headers.Authorization = `Bearer ${token}`;
	}
	return config;
});
```

Before releasing private routes, `isTokenValid()` decodes the JWT payload and checks the `exp` claim. If the token is missing, malformed or expired, it is cleared and the user is redirected to `/login`.

## 🗺️ Application Routes

| Route                         | Access    | Description                        |
| ----------------------------- | --------- | ---------------------------------- |
| `/login`                      | Public    | User authentication                |
| `/cadastrar`                  | Public    | Account creation                   |
| `/recuperar`                  | Public    | Password recovery                  |
| `/dashboard`                  | Protected | Overview                           |
| `/projetos`                   | Protected | Project list                       |
| `/incluir`                    | Protected | Create project                     |
| `/projetos/:id/editar`        | Protected | Edit project and tasks             |
| `/projetos/:id/visualizar`    | Protected | Project details                    |
| `/relatorios`                 | Protected | Generate and download reports      |

The root (`/`) and any unknown route redirect to `/dashboard`.

## 🔌 API Integration

Server state is managed by TanStack Query, with cache invalidation after every mutation.

| Hook                       | Consumed endpoints                                                                        |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| `useProjetos`              | `GET /projetos`, `POST /projetos/incluir`, `PUT /projetos/:id`, `DELETE /projetos/:id`      |
| `useTarefas`               | `GET /projetos/:id/tarefas`, `POST /projetos/:id/tarefas`, `PUT /tarefas/:id`, `DELETE /tarefas/:id` |
| `usePassword`              | `POST /password/forgot`, `POST /password/reset`                                             |
| `useRelatorioPdf`          | `GET /relatorios/item/:id/pdf`                                                              |

Full endpoint documentation lives in the API repository: [hourlog-backend](https://github.com/evelynlacerda/hourlog-backend).

## 🚀 Deployment (Vercel)

Automatic deployment on every push to the main branch.

`VITE_API_URL` must be registered under **Vercel → Project → Settings → Environment Variables**.

Since this is an SPA, `vercel.json` rewrites every extensionless route to `index.html`, preventing 404s when reloading inner pages:

```json
{
	"rewrites": [{ "source": "/((?!.*\\..*).*)", "destination": "/index.html" }]
}
```
